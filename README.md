# ইউনিয়ন ভোটার তালিকা (Union Voter List)

একটি আধুনিক এবং দ্রুতগতির ইউনিয়ন ভোটার তালিকা ও ভোটার অনুসন্ধান React অ্যাপ্লিকেশন।

## প্রযুক্তিগত কাঠামো (Technology Stack)

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4
- **Backend / API**: Express 4, tsx
- **Authentication**: Firebase Authentication
- **Typography & Font**: Noto Sans Bengali

## মূল ফিচারসমূহ (Core Features)

1. **নিরাপদ লগইন ও সিঙ্গেল সেশন গার্ড (Authentication & Single Device Session)**:
   - Firebase Auth (ইমেইল ও পাসওয়ার্ড)
   - পাসওয়ার্ড দেখা/লুকানোর টগল এবং পাসওয়ার্ড ভুলে যাওয়ার রিসেট সুবিধা
   - এক ডিভাইসে এক সেশন (অন্য কোনো ডিভাইসে লগইন করলে বর্তমান ডিভাইসে তাৎক্ষণিক নোটিফিকেশন সহ অটো-লগআউট)

2. **গ্রাম নির্বাচন ও পরিসংখ্যান (Village Selector & Stats)**:
   - ইউনিয়নের সকল গ্রামের তালিকা
   - গ্রামভিত্তিক মোট সক্রিয় ভোটার, পুরুষ ও মহিলা ভোটারের সঠিক পরিসংখ্যান
   - সকল গ্রাম জুড়ে এক ক্লিকে গ্লোবাল সার্চ (🔍)

3. **উন্নত ভোটার অনুসন্ধান (Advanced Voter Search)**:
   - নাম, পিতার নাম, মাতার নাম দিয়ে দ্রুত অনুসন্ধান (স্বয়ংক্রিয় বাংলা বর্ণ স্বাভাবিকীকরণ: য়, ড়, ঢ়)
   - জন্ম তারিখ দিয়ে অনুসন্ধান (স্বয়ংক্রিয় দিন/মাস/বছর ফরম্যাটিং ও বাংলা সংখ্যার রূপান্তর)
   - পেশা ও লিঙ্গ ভিত্তিক ফিল্টারিং
   - স্থানান্তরিত বা কর্তিত ভোটার ফিল্টারিং
   - সম্পূর্ণ তালিকা প্রদর্শন মোড
   - পেশাভিত্তিক লাইভ ব্যাজ ও সংখ্যা পরিসংখ্যান

4. **ভোটার কার্ড ও অ্যাকশন (Voter Card Actions)**:
   - ভোটারের ক্রমিক নং, নাম, পিতা, মাতা, জন্ম তারিখ, স্বয়ংক্রিয়ভাবে হিসাবকৃত বয়স, পেশা, ভোটার আইডি ও ঠিকানা
   - স্থানান্তরিত/কর্তিত ভোটারদের জন্য বিশেষ শনাক্তকারী লাল ব্যাজ ও ক্রস-আউট
   - 📋 এক ক্লিকে সম্পূর্ণ ভোটার তথ্য ক্লিপবোর্ডে কপি
   - 🖨️ সরাসরি প্রাতিষ্ঠানিক ফরম্যাটে সিঙ্গেল ভোটার প্রিন্ট প্রিভিউ
   - ইনফিনিট স্ক্রলিং ও পারফরম্যান্স-অপ্টিমাইজড ব্যাচ রেন্ডারিং
